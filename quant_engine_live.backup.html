        Real data kaise jodein

        Is published page se bahar network call allowed nahi hai, isliye yahan live feed ek built-in market simulator hai (stop-run, absorption aur reversal scenarios ke saath). Same engine ko apne broker feed se chalane ke liye is file ko local ya apne server par kholo aur ticks QuantEngine.ingest me bhejo. Option chain ke liye setChain use karo.

        const ws = new WebSocket('wss://YOUR-FEED');
ws.onmessage = e => {
  const k = JSON.parse(e.data);
  QuantEngine.ingest({ts: Date.now(), price: k.last_price, qty: k.last_quantity,
    bid: k.depth.buy[0].price, ask: k.depth.sell[0].price,
    bidQty: k.depth.buy[0].quantity, askQty: k.depth.sell[0].quantity});
};
// real option chain (OI in units, iv as decimal)
QuantEngine.setChain({K:[24800,24850,24900], cOI:[...], pOI:[...], iv:[0.14,0.13,0.125], days:2});

        Yeh educational analytics tool hai, trading advice nahi. Simulator ke results (win rate, P&L) sirf code ko check karte hain, strategy ka edge prove nahi karte, kyunki simulator mein setups khud daale gaye hain. Real edge ke liye real data par backtest aur kam se kam 30 din paper trading karo. Option OI synthetic hai jab tak aap real chain na dein. NIFTY lot size 65 maana gaya hai (NSE revision, Dec 2025 se). Har Jan/Jul exchange circular se verify karein.
